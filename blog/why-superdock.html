Why one Dock icon per Chrome profile

27 August 2026

If you run more than one Chrome profile, you already know the problem. Work in one, a client in another, personal in a third, and macOS shows you a single Chrome icon in the Dock for all of them. Click it and you get a pile of windows with no way to tell which profile each belongs to.

This happens because macOS gives one Dock icon per running program, and every Chrome profile runs inside the same Chrome program. The Dock has no idea profiles exist.

Why the usual fixes are worse

The tools that try to solve this run a separate copy of Chrome for each profile. That works, but it costs you memory for every extra copy, and it makes you log in again in each one. On a laptop with a handful of profiles, that adds up fast.

Superdock takes a different path. It draws its own Dock, so it can show one tile per profile, each with that profile's own picture, while still using your single real Chrome. No second copy, no logging in again.

Everything else stays familiar

The goal was never to replace your Dock with something that feels foreign. Icon size, spacing and the way it looks were all measured against the real macOS Dock and matched. A profile tile pins, drags and behaves like any other icon. The only difference you notice is that your profiles finally have their own icons.

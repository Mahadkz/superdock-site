The one thing no other dock can do

One icon per profile. No second Chrome.

Work, client, personal. If you run several Chrome identities, the Dock has never helped you switch, because macOS collapses them all into a single icon.

Split Dock draws its own tiles, so each profile gets its own icon with its own avatar. It uses your real Chrome, so there's no extra copy eating memory and no logging in again.

Know before you click

Window previews that stay in their lane.

Hover any tile and see its open windows before you switch. Editor windows lead with the workspace, not the file, so you land on the right one the first time.

Hover a profile and you see only that profile's windows. Nothing from your other identities leaks in.

One click, every window

An instant overview of everything open.

Click the empty right side of the dock and every window fans out at once, so you can see all your work and jump straight to the one you need.

Click the left side to clear the desktop. Both are yours to set, or turn off, in a single tap.

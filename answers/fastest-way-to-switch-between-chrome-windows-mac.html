What is the fastest way to switch between Chrome windows on a Mac?

By Mahad Kazmi, developer of Superdock. Updated 3 September 2026.

Short answer. For two windows, Command-Backtick. For more, or for windows spread across profiles, the fastest path is a Dock tile per profile: one click opens the right profile's windows, right-click lists only them, and Option-Tab shows every Chrome window with a thumbnail labelled by profile. Superdock provides all three.

The built-in shortcuts and where they fall short

  • Command-Backtick cycles the front app's windows in a fixed order, with no preview. Fine for two, slow for six.
  • Command-Tab lands on whichever Chrome window was last in front, which is usually not the one you want.
  • Right-clicking the Chrome Dock icon lists window titles, but every profile's windows are mixed together.
  • Chrome's Window menu lists windows for the front profile only.

Three faster paths

  1. Click the profile tile. With Superdock, each Chrome profile has its own Dock tile. One click brings that profile's windows forward; a second click cycles them.
  2. Right-click the tile for a list of only that profile's windows, or hover for thumbnails.
  3. Option-Tab for the window switcher: every window of every app, most recent first, Chrome entries labelled by profile.

Frequently asked questions

Does this need separate Chrome instances?

No. Chrome runs as one app; Superdock attributes windows to profiles from their titles.

What about Chrome windows on another display?

With a dock on every display, each dock lists the Chrome windows on its own screen; the switcher shows all of them.

Why does Command-Tab not bring back minimized windows on a Mac?

By Mahad Kazmi, developer of Superdock. Updated 3 September 2026.

Short answer. Because Command-Tab activates an app, not a window, and macOS considers a minimized window to be parked in the Dock rather than part of the app's visible set. Holding Option while releasing Command restores one minimized window; a window switcher such as Superdock's lists every window, minimized ones included, so you pick the one you want.

The Option trick

Press Command-Tab, keep Command held, move to the app, then hold Option before you let go of Command. macOS un-minimizes one window of that app. It works for a single window and is easy to fumble, which is why most people never rely on it.

A switcher that treats minimized windows as windows

Superdock's window switcher shows minimized windows dimmed in the same list as everything else, most recent first. Selecting one restores it and brings it forward. Hover previews in the dock list them too, so a minimized Chrome window is one click away from its profile tile.

Apple's own way around it

In Settings, Desktop & Dock, turning on "Minimize windows into application icon" keeps minimized windows under the app tile instead of the right end of the Dock, which makes them easier to find by right-clicking the app. It does not change Command-Tab.

Frequently asked questions

Does Superdock change the Command-Tab shortcut?

Only if you ask it to. By default its switcher is on Option-Tab and Apple's app switcher stays as it is.

Are minimized windows shown in previews?

Yes, and clicking one restores it.

How do I Alt-Tab between windows on a Mac like Windows?

By Mahad Kazmi, developer of Superdock. Updated 3 September 2026.

Short answer. Out of the box you cannot: Command-Tab cycles apps and Command-Backtick cycles the windows of the front app only. To move through every open window with thumbnails, most recent first, install a switcher. Superdock has one built in, and AltTab is a free, open-source alternative if you only want the switcher.

What macOS gives you

ShortcutWhat it cyclesThumbnails
Command-TabApps, one entry per appNo, icons only
Command-Backtick (Command-`)Windows of the front appNo
Mission Control (Control-Up)Shows everything, no cyclingYes
App Exposé (Control-Down)Front app's windows spread outYes

Getting the Windows behaviour

  1. Turn on Superdock's window switcher from the menu bar icon (Window Switcher) or in Settings, Behavior.
  2. Hold Option and press Tab. Every window, from every app, appears with a thumbnail and title, most recent first. Tab moves forward, Shift-Tab back, arrows work, Escape cancels.
  3. Release Option to bring the selected window forward, even if it was minimized.
  4. Prefer Command-Tab? Pick it in the same setting and Superdock takes over Apple's app switcher while it runs.

Chrome windows by profile

The switcher labels each Chrome window with its profile, so a work window and a personal window are two distinct entries instead of two identical Chrome icons. That is the case that sends most Windows switchers looking for this in the first place.

Frequently asked questions

Is AltTab free?

Yes. AltTab is open source and does only switching. Superdock's switcher is one part of a dock that also separates Chrome profiles, previews windows and runs on every display; the dock itself is free too.

Do the thumbnails need Screen Recording?

For live thumbnails, yes, and it is optional. Without it the switcher shows the app icon and window title.

Can I switch between windows of the same app only?

Yes: Command-Backtick still works, and the switcher can be filtered to the current app.

How do I switch between windows of the same app on a Mac?

By Mahad Kazmi, developer of Superdock. Updated 10 September 2026.

Short answer. Press Command and the backtick key, the one above Tab, to cycle the windows of the app you are already in. Control-Down spreads the front app's windows out on screen. Neither shows minimized windows in the cycle, which is the usual complaint. A window switcher lists every window with a thumbnail, minimized ones included, and can be filtered to the current app.

The built-in shortcuts

  • Command-Backtick (Command-`) moves to the next window of the front app. Add Shift to go backwards.
  • Control-Down is App Exposé, which spreads the front app's windows out so you can click one.
  • Window menu lists every window of the app, including minimized ones, at the bottom.

Why the backtick shortcut disappoints people

Command-Backtick skips minimized windows entirely, so a window you tucked away is invisible to the cycle. It also gives no preview, so with four similar documents open you are cycling blind. On a non-US keyboard layout the backtick key is often somewhere else, which makes the shortcut awkward to reach.

A switcher filtered to one app

  1. Enable the window switcher in Superdock, in Settings, Behavior.
  2. Hold Option and press Tab for every window, or Option and backtick to cycle within the frontmost app only.
  3. Pick by thumbnail. Minimized windows appear too, dimmed, and are restored when you select one.

Chrome windows across profiles

If the app is Chrome, windows from different profiles look identical in every built-in switcher. Superdock labels each Chrome window with its profile, so a work window and a personal window are two clearly distinct entries rather than two identical Chrome icons.

Frequently asked questions

What is the backtick key?

The key above Tab on a US layout, sharing a key with the tilde. On other layouts it sits elsewhere, which is part of why the shortcut is unpopular.

Why does Command-Backtick skip some windows?

It only cycles windows of the frontmost app and ignores minimized ones. The app's Window menu lists everything, minimized windows included.

Can I see thumbnails of each window?

Not with the built-in shortcuts. App Exposé shows the front app's windows spread out, and a window switcher shows thumbnails in a list.

Does this work across Spaces?

The built-in shortcuts move you to the Space the window is on. A switcher lists windows from every Space in one place.

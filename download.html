Download Split Dock

Split Dock runs on macOS 13 and later. It is a free 14-day trial, no account needed. Every Chrome profile gets its own Dock icon during the trial; after that the rest of the Dock keeps working, and a license brings the profile icons back.

Download the latest release

The download link goes live with the first signed release. The app is signed and notarized by Apple, so it opens with a double-click.

Building it yourself

Split Dock is free software under the GNU GPL v3. You are free to build it from source instead of buying the ready-to-run app. The source lives with each release.

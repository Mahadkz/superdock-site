# Superdock vs DockFix

By Mahad Kazmi, developer of Superdock. Updated 3 September 2026.

Short answer. DockFix is a customisation dock: colours, opacity, custom icons, widgets, a file shelf and community presets, with a 5.0 rewrite that its site says aims for a native look. Choose Superdock if you want zero visual change and per-profile Chrome tiles, previews, Alt-Tab and a dock per display, free.

DockFix is a customisation dock: colours, opacity, custom icons, widgets, a file shelf and community presets, with a 5.0 rewrite that its site says aims for a native look. Superdock is the opposite bet: one look, Apple's, and new behaviour underneath.

## Choose DockFix if
You want themes, widgets in the dock, custom icons and presets, and you enjoy configuring.

## Choose Superdock if
You want zero visual change and per-profile Chrome tiles, previews, Alt-Tab and a dock per display, free. Superdock has no themes on purpose.

## Try both
Superdock is free to download and the Chrome profile icons are free for 14 days. Run one dock at a time: two apps watching windows at once can freeze the desktop.

# Superdock vs DockDoor

By Mahad Kazmi, developer of Superdock. Updated 3 September 2026.

Short answer. DockDoor is the app most people find first when they want Windows-style hover previews on a Mac. Choose Superdock if you live in several Chrome profiles: DockDoor cannot split them because it does not own the tiles.

DockDoor is the app most people find first when they want Windows-style hover previews on a Mac. It leaves Apple's Dock in place and draws previews and an Alt-Tab switcher on top of it. Superdock replaces the Dock with an identical-looking one so it can change the tiles themselves.

## Choose DockDoor if
You want to keep Apple's Dock untouched, you only need previews and a switcher, or you prefer open-source software. DockDoor's core is free and it also bundles media controls, calendar hovers and a folder pop-up.

## Choose Superdock if
You live in several Chrome profiles: DockDoor cannot split them because it does not own the tiles. You also want a dock on each display, clickable dock ends, or Tahoe windows kept above the dock. Superdock's dock is free too; only the profile icons are paid.

## Try both
Superdock is free to download and the Chrome profile icons are free for 14 days. Run one dock at a time: two apps watching windows at once can freeze the desktop.

## Frequently asked questions

### Can I run DockDoor and Superdock together?
Not recommended. Both watch windows through Accessibility, and two docks polling at once can freeze the desktop. Pick one.

### Is DockDoor free?
Yes. The Free version adds previews and switching to Apple's Dock; DockDoor Pro, a separate Dock replacement, is $20 once for 3 Macs.

### Does Superdock have previews like DockDoor?
Yes: hover a tile for live thumbnails with titles, click to switch, and previews on a Chrome profile tile show only that profile's windows.

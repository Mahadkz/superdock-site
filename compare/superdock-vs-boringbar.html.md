# Superdock vs boringBar

By Mahad Kazmi, developer of Superdock. Updated 3 September 2026.

Short answer. boringBar drew 500 points on Hacker News for a simple taskbar that shows the windows in the current workspace instead of a Dock that, as its author put it, mixes everything together. Choose Superdock if you want to keep the Dock look and gain per-profile Chrome tiles, previews, Alt-Tab and a dock per display that shows the right apps on the right screen..

boringBar drew 500 points on Hacker News for a simple taskbar that shows the windows in the current workspace instead of a Dock that, as its author put it, mixes everything together. Superdock takes the other road: keep the Dock, fix its tiles.

## Side by side

|  | Superdock | boringBar |
| Approach | Replaces the Dock with a pixel-matched copy of Apple's | A taskbar-style bar that lists the windows of the current workspace |
| Price | Dock free; Chrome profile icons $7.99 once (up to 5 Macs) | Not stated on its site |
| One Dock icon per Chrome profile | Yes, one icon per profile in one Chrome process | No |
| Window previews on hover | Yes | Not stated on its site |
| Alt-Tab window switcher | Yes, Option-Tab or Command-Tab | Not stated on its site |
| Dock on every display | Yes, a dock on every display, per-display running apps | Reported issues: early users on Hacker News reported bars showing the wrong display's windows |
| Looks like Apple's Dock | Yes, measured against Apple's Dock on macOS 26 | No, a bar, not a Dock |
| Clickable dock ends | Yes, Show Desktop / Mission Control / Stage Manager | No |
| Minimum macOS | macOS 14 | Not stated on its site |
| Open source | No (closed source, notarized) | An open-source clone (OpenBoringBar) exists |

We make Superdock. Facts about boringBar come from its own website as read on 3 September 2026; "not stated" means the page did not say. Tell us at hello@superdock.app if something is out of date.

## Choose boringBar if
You want a minimal window list per workspace and you like the GNOME or Windows taskbar model.

## Choose Superdock if
You want to keep the Dock look and gain per-profile Chrome tiles, previews, Alt-Tab and a dock per display that shows the right apps on the right screen.

## Try both
Superdock is free to download and the Chrome profile icons are free for 14 days. Run one dock at a time: two apps watching windows at once can freeze the desktop.

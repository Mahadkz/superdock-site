# Superdock vs ExtraDock

By Mahad Kazmi, developer of Superdock. Updated 3 September 2026.

Short answer. ExtraDock adds more docks: floating panels anywhere on any screen with widgets, shelves and app folders. Choose Superdock if you want the one Dock you already know, on every display, with each Chrome profile as its own tile, previews and Alt-Tab, and no yearly fee..

ExtraDock adds more docks: floating panels anywhere on any screen with widgets, shelves and app folders. Superdock is one dock that looks like Apple's, on every screen, with different tiles.

## Side by side

|  | Superdock | ExtraDock |
| Approach | Replaces the Dock with a pixel-matched copy of Apple's | Adds extra floating docks beside Apple's (can also replace it) |
| Price | Dock free; Chrome profile icons $7.99 once (up to 5 Macs) | $14.99 a year, $27.90 lifetime per device, $69.90 for 5 Macs |
| One Dock icon per Chrome profile | Yes, one icon per profile in one Chrome process | No |
| Window previews on hover | Yes | Not stated on its site |
| Alt-Tab window switcher | Yes, Option-Tab or Command-Tab | No |
| Dock on every display | Yes, a dock on every display, per-display running apps | Yes, docks attached to specific displays |
| Looks like Apple's Dock | Yes, measured against Apple's Dock on macOS 26 | Configurable, Liquid Glass themes |
| Clickable dock ends | Yes, Show Desktop / Mission Control / Stage Manager | No |
| Minimum macOS | macOS 14 | macOS 26 (v5); v4 for 12 to 15 |
| Open source | No (closed source, notarized) | Not stated on its site |

We make Superdock. Facts about ExtraDock come from its own website as read on 3 September 2026; "not stated" means the page did not say. Tell us at hello@superdock.app if something is out of date.

## Choose ExtraDock if
You want several docks for different purposes, widgets and shelves, and a dock that stays on a chosen display.

## Choose Superdock if
You want the one Dock you already know, on every display, with each Chrome profile as its own tile, previews and Alt-Tab, and no yearly fee.

## Try both
Superdock is free to download and the Chrome profile icons are free for 14 days. Run one dock at a time: two apps watching windows at once can freeze the desktop.

## Frequently asked questions

### Is ExtraDock a subscription?
Its site offers a one-year licence at $14.99 or lifetime options. Superdock has no subscription: the dock is free and the profile feature is $7.99 once.

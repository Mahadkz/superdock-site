# Image prompts, batch 1 of 3 (images 1 to 24)

One prompt per line. Paste one at a time into Gemini.

**Palette is fixed across all sixty:** deep charcoal grounds `#08080a` to
`#1a1a1f`, raised charcoal `#343437` to `#3a3a3e`, milk-white tiles `#ffffff`,
one accent blue light `#2e93ff` deepening to `#1669e0`. Dark images, because the
site is dark. Blue is the lit element only, never the field.

**Object vocabulary is fixed:** upright white tiles, tiles fanning from one, a
rail of tiles, planes, a lit empty slot. No chrome, no glass, no paperwork, no
freight.

Variants: **a** = object right, text space left. **b** = object left, text space
right. **c** = object low, text space top.

- Answer the question in the first paragraph. Do not make the reader scroll for it.

- Listicle icons: official source only, stored in `assets/apps/`, linked to the
  official site. Never imply endorsement.

## Per piece checklist
1. Search the SERP for the exact target question first. Read the top 3 results.
2. Note what each one gets wrong or leaves out. That gap is the reason to publish.
3. Write the answer in one paragraph, then the detail.
4. Add FAQ entries that name the competitors people are actually comparing.
5. Internal link: 2 to 3 siblings, 1 pillar.
6. Generate the markdown twin.
7. Add to sitemap, answers or blog index, and llms.txt.
8. Audit for em dashes. Expect zero.
9. Render locally and screenshot before publishing.

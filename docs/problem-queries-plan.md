# Problem-shaped queries
12 September 2026. 32 queries mapped against live SERPs, checked against the PRD
so we never claim a feature we do not ship.

## Why these are the easiest SEO we have

A forum thread ranking first with no product answering is the weakest SERP there
is. Seven of these have positions 1 to 3 held **entirely** by Apple Discussions,
Stack Exchange, Superuser or Reddit, with no product anywhere.

## Table 1. The empty SERPs, write these first

| # | Query | Positions 1 to 3 | We honestly answer? |
|---|---|---|---|
| 1 | why does clicking a dock icon bring all windows to front | BetterTouchTool forum, Superuser, Ask Different. **All forum** | **Yes.** Right-click and hover give a per-window list |
| 2 | shortcut to toggle between windows of the same app | Ask Different, Reddit, Superuser | **Yes, and it is our exact wedge.** The #2 result opens "I opened two Google Chrome windows (because I am using multiple Gmails)" |
| 3 | keyboard shortcut to restore a minimized window | Apple Discussions, Hacker News, Ask Different. Only product is a thin affiliate blog | **Yes.** The switcher lists minimized windows, dimmed |
| 4 | cmd tab does not work on hidden or minimized windows | Ask Different, Apple, Superuser | **Yes.** Same switcher |
| 5 | how to add spacers or separators between dock icons | Three hobbyist blogs all publishing the same `defaults write` recipe | **Yes.** Spacers, flexible spacers and dividers as real tiles, no Terminal |
| 6 | how to hide a running app from the dock while keeping it open | Reddit, Apple Discussions, Ask Different. Every answer is an Info.plist hack | **Yes.** Hidden Apps pane |
| 7 | toggle between multiple open Google profile accounts | Google support, YouTube, JustAnswer | **Yes.** One tile per profile |

**Query 2 is the highest intent-to-feature match found anywhere in the research.**
A stranger described our paid feature in 2015, it still ranks, and no product is
on the page.

## Table 3. DO NOT WRITE. We do not have the feature.

Writing these would overclaim, and the research was strict about it.

| Query | Why not |
|---|---|
| how to hide all apps except the one I'm using | That is native Cmd-Opt-H. We would look ignorant |
| how to make a window always on top | Four products own the SERP. **We do not float windows** |
| mac dock badge notification count not showing | **We do not render badges.** Badgeify owns it |
| remove the delay when the dock auto-hides | A one-line `defaults write` solves it. A product page reads as upsell |
| click twice on dock icon to minimize | **We do not implement click-to-minimize.** Only partially true |
| separate dock icon per window for any app | True for **Chrome profiles and minimized windows only**. Do not generalise to every app |

## Publishing note

These interleave with the listicles. The empty-SERP queries in table 1 are
cheaper to write than listicles (800 to 1,200 words, one clear answer) and should
be used to fill the days between larger pieces.

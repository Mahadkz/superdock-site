# Content clusters

Replaces the flat 14-item list in `content-queue.md`. A flat list does not build
authority: a cluster does. Each cluster has one pillar that targets the broad
head term, spokes that target long-tail variants, and internal links so the
spokes push authority into the pillar and the pillar distributes it back.

Rule: every spoke links up to its pillar and sideways to two siblings. The
pillar links down to every spoke. No orphan pages.

SERP evidence for every cluster is in `growth-research-2026-09-11.md`.

---

## Cluster A, "best Mac apps" (the reusable asset)

Why this cluster: every page ranking for these terms is a small app site, not a
publisher. noticky.app, notchia.app, chronoid.app, getdroppy.app, snapzy.app,
usevoicy.com, prettyprogress.app, theodorehq.com all rank with exactly one
strong listicle. This is the most winnable format we have, and the pillar URL is
the one we update forever as we ship more apps.

**Pillar: `/best-mac-apps/`** targeting "best mac apps 2026", "essential mac apps",
"must have mac apps". Category-organised, 30+ apps, real icons, honest verdicts.

Spokes:
| Slug | Target | Notes from SERP |
|---|---|---|
| best-mac-utility-apps | "best mac utility apps", "mac utilities" | The category Superdock actually belongs to. Missing from our plan entirely until now. |
| mac-apps-for-power-users | "mac power user apps" | timingapp.com ranks with this exact framing; Raycast, Hazel, BetterTouchTool, iStat Menus recur |
| best-free-mac-apps | "best free mac apps", "free mac apps no subscription" | getdroppy, snapzy, theodorehq all rank; our free positioning fits precisely |
| best-mac-apps-for-windows-switchers | "mac apps for windows users" | Our highest-intent audience. Reddit top answers are Rectangle, LinearMouse, Maccy, Ice |
| best-mac-apps-for-developers | "best mac apps for developers" | usevoicy, dev.to, derekseaman rank; secondary Chrome instances angle is ours |
| best-mac-apps-new-macbook | "new macbook apps", "just got a mac" | noticky owns this with 30+ picks; seasonal spike at Christmas |
| best-open-source-mac-apps | "open source mac apps" | We are not open source, so we appear only as the honest paid mention. Still worth the traffic. |

Superdock's slot in every one: **browser profile separation**, which appears on
none of the lists found. Use the notchia technique, be genuinely useful about
Raycast and Rectangle, then claim the empty category.

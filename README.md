# Split Dock — website and releases

This repository hosts the Split Dock website and its signed release downloads.
It is served at the project's GitHub Pages URL.

- `index.html` and the pages beside it are the site.
- `blog/` holds posts.
- Release DMGs and `appcast.xml` are published here by `Tools/release.sh` in the
  app repository; the app checks `appcast.xml` for updates.

Split Dock is free software under the GNU GPL v3. The application source is
released with each version; buying the app pays for the ready-to-run, signed,
notarized build with updates and support.
